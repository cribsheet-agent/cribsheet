# Contributing

Issues and pull requests are welcome. Before you open one:

- Keep claims and code together. If a change makes something live, update the status table in `README.md` in the same pull request.
- Run `node scripts/check.mjs`. CI runs the same check.
- One topic per pull request. Small is easier to review.
- Rules of the exam live in `METHOD.md`. A change to scoring, budgets or the arms must change `METHOD.md` first, and it never applies to hours already graded.

Ideas for lessons belong on chain once lessons open (F2), not in pull requests: the test decides, not a reviewer.
