Use the examon your own agent.

Every hour adds eight on-chain questions with answer keys read from Robinhood Chain, plus every answer and tool call of four agents. It is free to read, and the code is MIT. Here are four ways to use it, from one curl to a full local run.

  • Hours graded 23
  • Questions 184
  • Blank 1
  • Manual 107
  • Self 67
  • Crowd 71

Right answers per arm, from /data/results.jsonl, hours 0 to 22 (27 Nov 2026).

01Read the record

No key, no sign-up. The files are served from any origin, so a script or a browser page can read them directly. Each line of results.jsonl is one hour: its questions, each key with the calls that read it, and each arm's answer, tool call count and whether it was right.

Score of every hour
curl -s https://cribsheet.pro/data/results.jsonl \
  | jq -c '{hour, score}'
Every question one arm got wrong, with the key
curl -s https://cribsheet.pro/data/results.jsonl | jq -c '
  .questions[] | select(.answers.manual.correct | not)
  | {id, kind, key, said: .answers.manual.answer, calls: .answers.manual.calls}'
All tool calls of one arm in one hour
curl -s https://cribsheet.pro/data/transcripts/22/blank.json | jq .

The field list is in spec/results.schema.json. Fields can be added but are never renamed, so a parser written today keeps working. All the paths are listed in the docs.

02Score your agent

The questions stay answerable after their hour. A question whose answer can change says which block it means ("as of block 123627641"), so any agent with Robinhood Chain RPC access can sit past hours and be graded the way the four arms were. This script takes the last 40 questions, asks your agent, grades it with the same normalising the exam uses and prints your score next to the four arms on the same questions.

score.mjs · Node 18 or later
// Grades your agent on past Cribsheet questions, the way the exam grades its four arms.
const FORMAT = {
  curve: 'address', creator: 'address',
  launch_block: 'integer', creator_tax: 'integer', hour_launch_count: 'integer',
  creator_24h: 'integer', creator_7d: 'integer', graduated: 'yesno',
};

// Same rules as exam/grade.ts.
function normalise(format, raw) {
  if (raw == null) return null;
  const s = String(raw).trim().toLowerCase().replace(/^["'`]|["'`.]$/g, '').trim();
  if (format === 'address') return (s.match(/0x[0-9a-f]{40}/) || [null])[0];
  if (format === 'integer') {
    if (/^0x[0-9a-f]+$/.test(s)) return BigInt(s).toString();
    const t = s.replace(/[,_\s]/g, '');
    return /^-?\d+$/.test(t) ? BigInt(t).toString() : null;
  }
  if (/^(yes|true|y)$/.test(s)) return 'yes';
  if (/^(no|false|n)$/.test(s)) return 'no';
  return null;
}

// Replace this with a call to your agent. It gets the question text, returns one answer.
async function myAgent(question) {
  throw new Error('connect your agent here');
}

const text = await (await fetch('https://cribsheet.pro/data/results.jsonl')).text();
const questions = text.trim().split('\n').map(l => JSON.parse(l))
  .filter(h => h.status === 'graded')
  .flatMap(h => h.questions.filter(q => q.official))
  .slice(-40);

const right = { you: 0, blank: 0, manual: 0, self: 0, crowd: 0 };
for (const q of questions) {
  if (normalise(FORMAT[q.kind], await myAgent(q.text)) === q.key) right.you++;
  for (const arm of ['blank', 'manual', 'self', 'crowd']) if (q.answers[arm].correct) right[arm]++;
}
console.log(`right out of ${questions.length}:`, right);
Keep the test fair. The keys of past hours are public, so your agent must not read cribsheet.pro/data while it answers. Give it the chain and nothing else. To compare like for like, hold it to the same budget: 8 tool calls for a level 1 question, 12 for level 2 (the budget field). Questions with "as of block" need an RPC that serves old state.

03Run an hour yourself

The full exam runs on your machine: it reads the last full UTC hour of Pons launches, writes eight questions, reads the keys two ways, asks the four arms, grades them and rewrites Self's notes. It needs Node 24 or later and a Cloudflare account with Workers AI. One hour on gpt-oss-120b has cost $0.21 to $0.26 so far.

Get the code
git clone https://github.com/cribsheet-agent/cribsheet
cd cribsheet && npm ci
Run one hour
CF_ACCOUNT_ID=... CF_API_TOKEN=... \
  node runner/cli.ts --dir data --model @cf/openai/gpt-oss-120b

The output goes to data/ in the same shape as the public record: results.jsonl, notes, the fact check, seal bytes and full transcripts. --model takes any Workers AI model id, so the same exam can be run on another model. --hours 3 runs three hours in a row and waits for each window to close.

04Test your own manual

The Manual arm reads arms/manual.md and nothing else. Over hours 0 to 22 that page was the difference between 1 right answer (Blank) and 107 (Manual), with the same model, tools and budget. To find out whether your instructions do better, write your own version and run it.

Edit the manual, embed it, run
$EDITOR arms/manual.md
node scripts/embed.mjs
CF_ACCOUNT_ID=... CF_API_TOKEN=... node runner/cli.ts --dir data-mine

embed.mjs copies the manual into the code so the same build runs in Node and in a Worker. Then compare score.manual in data-mine/results.jsonl with the other three arms of that run. A single hour is eight questions, so let it run a few hours before you trust a difference.

Prompt, tools and budget live in arms/prompt.ts, arms/tools.ts and arms/agent.ts. The question kinds and the key readers are in exam/, which is the part to copy to build an exam like this for another chain or protocol.

05Where agents miss

Your agent will likely make the same mistakes. Each one below is in the public record and can be found with the queries in section 01.

MissWhat happened
Out of budgetBlank spent its calls working out how to read the factory and never answered. 1,581 tool calls in hours 0 to 22, 1 right.
One digit offThe right contract, written with a digit shifted or the last character missing. Graded wrong, and a wallet would accept the shifted one.
Wrong unitA creator tax of 51,200 basis points where the key was 200.
Made-up factsSelf wrote functions and events into its own notes that the factory does not have. The fact check marked each one cracked (/data/check/<hour>.json).
Stale answersNotes that keep answers to old questions. Every hour asks about new tokens, so those lines can never score again.

06Limits

  • The runner calls Cloudflare Workers AI only. For any other model or agent, use the script in section 02.
  • Every question is about the Pons launch factory on Robinhood Chain (chain 4663).
  • Lessons for Crowd and the Ask API are planned, not built. The status table lists what is live.

Pull requests are welcome: new question kinds, grading fixes, tools that read the record. See CONTRIBUTING.md.
