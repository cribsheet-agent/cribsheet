**Pons Launch Factory – Quick Reference**

**Key Event Signatures (keccak‑256)**
- `Launch(address,address)` → `0xe4b8baaa1c927a55ac28b7693040a55b0b48044cf0572d1fc3beb0f418054a20`
- `TokenCreated(address,address)` → `0xd5f9bdf12adf29dab0248c349842c3822d53ae2bb4f36352f301630d018c8139`
- `TokenCreated(address,address,string,string,uint256)` → `0x6e6ae68e7d7d45fbd855c40d1eaafa8de46c5fbec3ee26f1af88730e400bc92c`
- `Launch(address,address,string,string,uint256)` → `0xc6bc142cba2d8ddeb13a3cc6540722eec09f03f0bd02acc9d7d2318060ca9783`
- `Transfer(address,address,uint256)` → `0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef`

**Function Selectors**
- `bondingCurve()` → `0xeff1d50e`
- `creatorTax()` → `0xd727a021`

**EIP‑1967 Proxy Implementation Slot**
- Slot key: `0x360894a13ba1a3210667c828492db98dca3e2076cc3735a920a3ca505d382bbd`
- Read with `eth_getStorageAt` to obtain implementation address (if non‑zero).

**Common RPC Patterns**
- **Block numbers** must be hex strings, e.g. `"0x73621da"`. Convert to decimal when needed.
- **Log queries** (`eth_getLogs`) accept:
  ```json
  {
    "fromBlock":"0xHEX",
    "toBlock":"0xHEX",
    "address":"<factory‑address>",   // optional but reduces noise
    "topics":[<event‑hash>, <indexed‑param‑1>, …]
  }
  ```
- **Limits**: max 1 000 000 blocks per query; max 10 000 logs returned. Split large ranges accordingly.
- **Filtering by token**: token address is the second indexed param → topic[2] = `0x000…<token‑address>` (padded to 32 bytes).

**Typical Queries**
1. **Find deployer of a token**  
   - Use `TokenCreated` (or `Launch`) event.  
   - `topics[0] = TokenCreated hash`  
   - `topics[2] = padded token address`  
   - The first indexed param (topic[1]) is the creator address.

2. **Find launch block of a token**  
   - Same log query; the `blockNumber` field of the returned log is the launch block (hex → decimal).

3. **Count tokens in a range**  
   - Query `TokenCreated` logs over the range, split if >1 M blocks.  
   - Count returned logs.

4. **Read bonding curve address**  
   - Call `bondingCurve()` via `eth_call` with data `0xeff1d50e`.  
   - If the token is a proxy, first fetch implementation via the EIP‑1967 slot, then call on that address.

5. **Read creator tax**  
   - Call `creatorTax()` with data `0xd727a021`.  
   - May require archive node for historical block; otherwise use `latest`.

**Tips & Gotchas**
- `eth_getLogs` errors often stem from non‑hex block numbers or exceeding limits. Always use hex and chunk ranges.
- When a call reverts, verify if the contract is a proxy;
