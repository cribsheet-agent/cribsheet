**Function selectors**
- `bondingCurve()` → `0xeff1d50e`  
- `creatorTax()` → `0xd727a021`  
- `graduated()` → `0xe7c2b772` (used to check curve graduation)

**Log query pattern (use hex strings)**
```json
{
  "fromBlock":"0xHEX",
  "toBlock":"0xHEX",
  "address":"0x000000000000000000000000000000000000006e",   // factory
  "topics":[
    "<event‑hash>",                // topic[0]
    "0x000000000000000000000000<token>",   // topic[1] = token address (if needed)
    "0x000000000000000000000000<creator>"  // topic[2] = creator (if needed)
  ]
}
```
- **TokenCreated**: `topic[1]` = token address, `topic[2]` = creator address.  
- **Launch**: same indexing.

**Typical queries**
1. **Deployer of a token** – `TokenCreated` with `topic[1]=token`; read `topic[2]`.  
2. **Launch block** – same log; use `blockNumber`.  
3. **Count tokens in a range** – `TokenCreated` logs over the range, count entries.  
4. **Bonding‑curve address** – `eth_call` with data `0xeff1d50e`. If call reverts, check proxy slot then call on implementation.  
5. **Creator tax** – `eth_call` with data `0xd727a021`.  
6. **Graduation status** – `eth_call` with data `0xe7c2b772`; returns `bool`.

**RPC limits (observed on Robinhood node)**
- `eth_getLogs` **max 1,000,000 block span** per request.  
  - Split larger ranges or add the factory `address` filter to stay ≤ 1 M blocks.  
- `eth_blockNumber` returns hex string (e.g., `"0x7384ce6"`).  

**Gotchas**
- Use **hex** block numbers (`"0x..."`).  
- Calls may revert on proxies or if function absent; verify proxy status first.  
- `eth_getCode` works; a non‑empty bytecode indicates a contract (proxy detection
